# MangkukKembara
Collaboration Development Assignment Project

## Required development environment

- Flutter: 3.44.8 stable
- Dart: 3.12.2, included with Flutter

The Flutter client uses Supabase for Auth/data and a Supabase Edge Function for
signed Cloudinary image uploads. See [SUPABASE_CLOUDINARY_SETUP.md](SUPABASE_CLOUDINARY_SETUP.md)
before running the application against a new backend.
